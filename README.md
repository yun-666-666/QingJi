# 轻记

一个简单的 Android 记账软件，用来记录日常收支、整理账单、查看消费汇总，让记账轻松一点。

本项目由 **GPT6.1 + 6astra** 制作。

## 下载使用

支持 **Android 8.0 及以上版本**。

前往 [软件下载页](https://github.com/yun-666-666/QingJi/releases/latest)，下载 APK 后安装即可。

如果已经安装轻记，建议直接覆盖更新，不要先卸载，以免丢失手机里的本地账本。

## 当前版本

当前正式版为 **3.49.0**：移除额外启动画面，合并设置分组并精简说明，减少首页加载和刷新时的重复工作。保留通知记账、页面文字识别和日夜切换动效。

当前版本已移除内置 OCR 模型、依赖和功能入口。此前的 [3.48.0 OCR 预览版](https://github.com/yun-666-666/QingJi/releases/tag/v3.48.0-preview) 仅作为历史版本保留，该方向已停止开发。
